Background Pipeline

    

      
🤖 Background Pipeline

      

        Runs in the background using the VNC display — keeps sessions alive and avoids bot detection.
        Sponsorship sources (e.g. MyVisaJobs) are included automatically if configured in Settings.
      

      

        
        
        
        
        
      

      

    

    

      
🗑 Document Storage

      

        Tailored resumes and cover letters are saved to artifacts/ on disk.
        Pruning deletes the oldest files and keeps only the most recent ones.
        Also runs automatically after each successful apply.
      

      

        
        
        
        
        
      

    

    

      
📋 Add a Sponsorship Source URL

      

        Jobs discovered from these URLs will automatically receive high sponsorship confidence.

🔍 Job Discovery

    

      

        
Live discovery

        
Playwright controls the browser to search LinkedIn (and other platforms) in real-time

      

      
    

    

      Roles & locations come from config/profile.yml. Set Browser Mode to Headed to watch it live in noVNC. When AI Pipeline is ON, the LLM controls the browser and uses judgment to find jobs.
    

    

      
      
    

    

      
      

        
        
        
        
      

    

    

      

        
        
      

      

        
        
      

      

        
        
      

    

    

      Runtime ≈ max URLs × max actions × ~4s. Default: 40 jobs · 4 URLs · 15 actions ≈ 4 min max.
